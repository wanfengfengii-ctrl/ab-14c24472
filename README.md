# 寄存器加权混合复核台

纯前端（TypeScript + React + Vite）的模 **M = 2^k** 线性同余方程组审计台，针对
“标定记录只保存多个寄存器加权混合后的低位结果”这一场景：

- 模型：2..8 个未知寄存器 x₀..x_{n-1}，1..12 条等式，位宽 k ∈ 1..16，模数 M = 2^k；
  每个参数、系数与结果均为 0..M−1 的整数。
- 方程：对每行 i，`Σ_j a_ij · x_j ≡ b_i (mod M)`。
- 功能：
  - 表格编辑 / JSON 或文本导入系数矩阵 A 与结果向量 b；
  - 精确返回 **全部不同完整参数向量数量**（十进制字符串，BigInt，最大 2^128）；
  - 数量为零 / 一 / 更多时分别裁决 **无解 / 唯一解 / 多解**；
  - 多解时给出按寄存器输入顺序（x₀,x₁,…）字典序最小的两份完整参数见证；
  - 每份见证逐行回算，展示精确点积、点积 mod M 的余数与期望值；
  - 重复等式、全零等式合法且不重复计数；
  - 维度不匹配、非整数、数值越界均定位到具体矩阵/向量单元；
  - **改动任何输入立即重新校验并撤下旧裁决**；
  - 全部计算在浏览器本地完成，不调用任何业务后端。

## 算法（不枚举 M^n）

在局部环 Z/2^kZ 上做 Smith 消元：始终选择 2-adic 赋值最小的元素作主元，
通过行/列幺模变换（跟踪变量代换 x = Qz）化为对角形，主元为 2^{e₁},…,2^{eᵣ}。

- 解数 = `2^( e₁+…+eᵣ + k·(n−r) )`；
- 见证构造：z 参数空间的解是独立剩余类的直积，对任一原坐标 xₚ = Σ Q[p][i]z_i，
  其可行取值是一个 2 进子群陪集，最小非负代表由各项 2-adic 赋值直接算出；
  逐坐标贪心得到全局字典序最小解，再从最右端可进位坐标得到第二份。
  复杂度约 O(n²·m·k) 的多项式次 BigInt 运算，与 M^n 无关。

## 本地开发

```bash
npm install
npm run dev       # 开发服务器
npm run test      # vitest（含对 k≤3 全部输入规模的暴力枚举交叉验证）
npm run build     # 类型检查 + 静态构建到 dist/
npm run preview   # 预览构建产物
```

## Docker

构建并运行静态应用（宿主机端口通过 `HOST_PORT` 配置，默认 8080，带健康检查）：

```bash
docker compose up --build
# 自定义端口
HOST_PORT=9090 docker compose up --build
```

一次性复核服务（运行单元测试、静态构建、HTTP 冒烟，**自行退出并以退出码报告成功与否**）：

```bash
docker compose --profile verify run --rm --build verify
echo $?   # 0 表示测试、构建、冒烟全部通过
```

`Dockerfile` 为多阶段构建：`deps` → `build` → `runtime`（nginx 托管纯静态文件，
镜像内含 HEALTHCHECK）；`verify` 目标复用依赖层执行 `scripts/verify.sh`。

## 导入格式

JSON：

```json
{ "k": 3, "n": 2, "m": 2, "A": [[1, 2], [4, 0]], "b": [3, 5] }
```

文本（每行一条等式，`=` 或 `;` 分隔结果，缺省分隔符时末个数字即结果）：

```
# k=3 n=2
1, 2 = 3
4 0 ; 5
```
